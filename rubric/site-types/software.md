Judge answerability as an agent evaluating or integrating the product for someone: what it does, who it is for, how to install it or sign up, what it costs, and how to get support or make contact. For pricing, an open-source licence stated plainly, a free tier or a published plan structure each count as a clear answer; the fault is silence about cost and licence. Documentation that reads without JavaScript, an OpenAPI description, an MCP server and machine-usable sign-up or API routes carry the most weight, because this is a site agents will act through rather than only read.
