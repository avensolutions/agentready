Judge answerability as an agent acting for a prospective client: what services are offered, for whom and where, how the engagement works, what it costs or how a quote is obtained, and how to make contact or book. Published prices are not expected, but an explanation of how pricing works is. For actionability, the question is whether an enquiry or booking has a route an agent can use: an email address, a plain HTML form, a booking link or an API. An OpenAPI description and an MCP server are not expected of a services business.
