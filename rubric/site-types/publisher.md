This site exists to be read, quoted and cited. Judge answerability by whether an agent can tell what the publication covers, who publishes it, who it is written for and how to reach the publisher. Do not expect prices or a sales route. Clean content in the initial HTML, markdown alternates and llms-full.txt carry the most value here, because agents will read and quote this site at length. Judge the API documentation check on whether any programmatic access to the content exists (feeds, an API or an MCP server), and treat feeds as a reasonable answer.
