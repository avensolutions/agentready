Judge whether the HTML uses structure an agent can rely on: a single h1 that names the page, a logical heading hierarchy without skipped levels, landmarks (header, nav, main, footer), lists and tables for list-like and tabular content, descriptive link text rather than "click here", and a title element that matches the page. Look at the heading outlines and landmark counts in the evidence for the home page and sampled pages.

Scoring:
- 0: No headings or landmarks; content is undifferentiated divs and spans.
- 1: Headings exist but are used for styling, with multiple or missing h1 elements and no landmarks.
- 2: A mostly sensible heading outline on some pages, with inconsistent use of landmarks and link text.
- 3: A clear heading hierarchy and landmarks on the sampled pages, with minor lapses.
- 4: Every sampled page has a single h1, an orderly heading hierarchy, landmarks and descriptive links.
