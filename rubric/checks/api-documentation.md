Judge whether the organisation offers a public API and documents it where an agent can find it. Look at the probes for common documentation paths (/api, /docs, /developers, /api-docs) and at links in the page text that point to developer documentation, and at whether the documentation is readable without JavaScript. Not every organisation needs an API; if the offering is purely a service delivered by people, note that and score on whether any programmatic route exists for the actions a customer would take (booking, enquiry, ordering).

Scoring:
- 0: No API, no developer documentation and no mention of programmatic access.
- 1: An API is mentioned but there is no reachable documentation.
- 2: Documentation exists but is thin, out of date or only usable through a JavaScript application.
- 3: Reachable, readable documentation for a public API covering the main actions.
- 4: Complete, readable API documentation with authentication, examples and a clear starting point, linked from the site.
