Whether an agent that fetches a page with a plain HTTP client gets the content. Most agents do not run JavaScript, pay for every token they read and rely on document structure to find the substance. This covers content in the initial HTML, markdown alternates, the ratio of content to chrome, and semantic structure such as headings and landmarks.
